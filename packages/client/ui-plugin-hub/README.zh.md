# @deepseek-ai/dsh-client-ui-plugin-hub

[English](README.md) | 中文

## 概述

**插件中心**列出管理员为当前登录账号批准的插件，并把内部宿主组合包、加载行、高权限工具和 generative-ui 排除在遂意产品界面之外。搜索与分类筛选后，卡片显示图案、发布版本、风险和已批准工具数量。详情对话框说明已批准的能力与权限；添加必须显式确认，已添加插件可以启用、停用或移除。页面只读取 Host 的 typed `pluginHub` Remote，目录未配置时显示诚实的不可用状态。

<a id="use-this-package"></a>
## 使用本包

从侧栏打开**插件中心**；遂意构建之外也可以从上游插件页的标签页进入。页面标题和副标题为**插件中心**与**查看当前账号可用的插件**。两个标签页是**全部插件**和**已添加**，后者数量为已授权条目。搜索与标签页在同一行，刷新是带 tooltip 的图标按钮。分类按钮按目录顺序排列，最后是**全部**。结果行显示当前卡片数量，并标明当前账号。

宽屏下卡片使用原型的三列网格，1100px 以下两列，640px 以下一列。每张卡片显示已发布图案或共享默认图案、分类和已批准工具数量、发布版本以及一个操作。未添加的卡片显示风险等级；已添加的卡片显示**已停用**、**已启用**、**添加中**或**需重试**。实例或操作失败时显示**需重试**和经过清理的 Host 详情。悬停抬升只在可悬停指针下生效；卡片操作、分类、标签页和对话框关闭按钮都保留可见焦点环。

选择标题或**查看权限**打开插件对话框。它显示管理员批准目录、当前状态、风险等级、身份范围、账号范围和服务端授权方式。事实之后是已批准能力、这些工具的权限说明，以及服务端执行授权的提示。已添加插件提供**停用**或**启用**以及**移除插件**；未添加插件提供**查看授权并添加**。

添加会打开权限确认对话框，重复展示已批准工具及其说明，说明授权由服务端执行，并在勾选确认前保持**确认添加**禁用。确认后才调用 Host；卡片显示添加中，随后显示 Host 的已添加但停用、连接或失败状态。已添加但未启用的行显示**已停用**状态和**启用**操作；已启用的行显示**停用**。移除会打开独立确认，然后撤回授权。

遂意构建即使在 Host 尚未启用目录时也注册独立插件中心，让页面解释该状态并提供**重新检查**。其他构建保留上游规则：未启用的市场不显示入口。可选的插件页标签页只在遂意构建之外、且 Host 报告市场已启用时存在。

### 空、加载与错误状态

首次读取显示四张卡片骨架。目录未启用时以说明和**重新检查**替代网格。已启用但没有发布条目时显示**暂无可用插件**和刷新操作。首次读取失败显示 Host 原因和**重试**；后续刷新失败保留已显示目录，并在上方增加可重试提示。

### 窄屏与长文本

窄屏下页面保留框架顶部安全区和 20px 左右内边距。卡片单列排列，对话框中的权限列表可滚动，长名称和描述换行，卡片描述截断为两行。粗指针下搜索框使用 16px 字号，避免 iOS Safari 聚焦时放大页面。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现内部说明——点击展开</summary>

### 注册

浏览器插件注册字典和 controller。在遂意构建（`DSH_CLIENT_BUILD_PROFILE=suiyi`）中，它在插件生命周期内注册 `sidebar.panellist` 入口和 `plugin-hub` 主面板；其他构建中两者只在 Host 报告市场启用时存在，并同时注册可选的 `plugins.tab` 条目。插件注入 `remote.pluginHub`，因此在 Host 提供该命名空间前 fiber 保持等待。

### 状态与读取

`PluginHubController` 发布一个快照 store。插件加载时读取一次目录，`ensure()` 保持幂等。`reload()` 重试失败的读取；`refresh()` 请求 Host 重新核对已发布目录，并在其他读取进行时忽略。只有当前连接代次的最新读取会发布，因此重置之前的迟到应答会被丢弃。读取失败时保留上一份快照，并发布一条本地化失败提示和经过清理的 Host 消息。实时 `watch` 帧更新同一个 store。

### 生命周期操作

每个插件同时只有一项操作。权限确认流程调用 `add(pluginId)`；已添加行的**启用**/**停用**调用 `enable(pluginId)`/`disable(pluginId)`；**移除**调用 `removeInstance(pluginId)`。controller 直接使用生成的类型化 `pluginHub` Remote，从实例读取 `added`，浏览器不保留兼容回退。成功后会重新读取目录，因此已添加但停用或连接中的实例无需再次刷新上游即可出现。失败时保留该行状态，并提供同一操作的重试。连接重置会清除进行中的操作及其失败记录，上一代次的迟到应答会被丢弃。

### 接缝归属

`src/client/contract.ts` 类型导入 Host 持有的 `/types` 声明，并读取生成的 Client Remote 组装中的 `ctx.remote.pluginHub`。已发布图案只接受 `http(s)` 和 `data:image/` 来源，并设置 `referrerpolicy="no-referrer"`；展示的每条 Host 消息都是经过清理的失败消息。页面不读取凭据或平台配置。

</details>

<a id="model-experience"></a>
## 模型体验

### 通过 Host 启用的插件工具

#### What the model sees

本包不产生文本。启用目录插件会请求 Host 的 `pluginHub` Remote 挂载已批准的 MCP 工具；工具 schema 与结果由 Host 和插件持有。

#### Token effect

本包不直接产生 token。已启用工具会在后续请求中通过 Host 加入其 schema 与结果。

#### KV 缓存影响

本包不直接影响缓存。添加、移除或替换插件工具时，Host 可能使受影响的请求前缀失效。

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>

- **目录成员由 Host 持有**——`added`、`add`、`enable`、`disable` 和 `removeInstance` 都来自类型化的 `pluginHub` Remote。浏览器只展示并请求这些状态，不自行推导或持久化第二份安装记录。
- **整份目录读取**——插件中心列出 Host 返回的全部可见插件并在本地筛选；没有分页或服务端搜索。
- **目录可用性决定数据**——未配置或未启用的市场会说明自身状态，而不是显示示例插件。浏览器不伪造业务数据。
- **Host 持有批准与执行**——浏览器目录和按钮状态不是授权。管理员批准目录，服务端执行工具调用时校验。
- **线上字符串原样显示**——分类名和工具说明由 Host 声明，因此按发布内容显示，不翻译。
- **遂意构建没有内部组合包管理器**——`ui-plugin-manager` 在 `DSH_CLIENT_BUILD_PROFILE=suiyi` 下直接返回、不注册；内置宿主组合包和行通过 profile 管理，不在此页展示。

### 开发备注

<details>
<summary>维护者的工作上下文——点击展开</summary>

组件测试使用快照 store 渲染目录、标签页、筛选、卡片、详情、权限确认、已添加但停用、移除、加载、未启用、空和失败状态。浏览器插件测试覆盖遂意插件中心注册和上游按启用状态增删的标签页。controller 测试覆盖读取顺序、迟到结果、重试、销毁，以及类型化的 add/enable/disable/remove 路径。样式表测试检查可悬停指针、三列到两列再到一列的网格、换行、焦点环、仅 token 颜色和减少动态效果。

Host 依赖为 `@deepseek-ai/dsh-plugin-hub-client` 及其 `pluginHub` Remote 命名空间，已接入 Web 应用组合。缺少该服务时插件 fiber 保持等待，不会出现插件中心；boot 组合和 Host 服务配置由主协调者负责。

</details>
